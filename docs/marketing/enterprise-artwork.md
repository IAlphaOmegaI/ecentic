# Enterprise marketing artwork

The live hero, procurement and closing compositions are real ASCII text: server-rendered `pre` elements made from `@`, `#`, `%`, `X`, `+`, `=`, `-`, `/` and `\\` characters. They contain no dots or bitmap backgrounds. The two 120 × 48 character compositions total about 8 KB of source text, use the platform monospace font, and inherit ecentic's white-on-blue treatment. Container sizing preserves the proportions at desktop and mobile widths. [ASCII text provenance](ascii-text-provenance.md) records the conversion and final previews.

The commerce source illustration was generated through the configured Azure `azure-image` CLI using gpt-image-2.5, 1536 × 1024, high quality. It depicts hands supporting an open parcel with catalog objects. The original is `output/enterprise-rebuild/ascii-commerce-source.png`. The initial alpha WebP and mobile WebP experiments are no longer requested by the live site; the final artwork is text. The existing canonical hands composition supplied the closing text silhouette. None of this decorative artwork is a product screenshot or customer evidence.

The latest user direction uses an off-white canvas (#F8F9FA), gray supporting-service panels confined inside rails, and a subtly rounded blue homepage surface with centered content and vertical construction lines. The hero has equal 24 px side/top margins, reduced to 16 px on mobile. No horizontal lines cross the hero. Shared guides are suppressed where structural content grids already draw borders, preventing doubled lines. Primary buttons match the cookie banner's 6 px radius; secondary actions, fields and selectors retain 2 px corners. These refinements intentionally supersede the initial uniformly square treatment. The navbar uses progressive 3/9/18 px backdrop blur and an in-flow menu portal that pushes the page down when opened; keyboard focus and layout are restored when it closes. ASCII movement uses the existing Motion wrapper once on entry, with a static composition for reduced-motion users.

Nine new Nucleo duotone icons were obtained through the installed licensed Nucleo CLI/catalog and transformed through the repository Turbo generator: plug sparkle, chart activity, file pen, shopping basket, globe pointer, file shield, city building, open book, and code. They are exported by `@zenncore/icons` with the `Commerce` prefix. Official provider marks are documented in [provider-logo-provenance.md](provider-logo-provenance.md).

The English and Spanish overview screenshots show the current `OverviewCharts` component with explicitly labeled sample values. The archived fixture is `output/enterprise-rebuild/screenshot-fixture.tsx.txt`; its temporary route was removed. Eight additional genuine Connect, Fix, Sell and Track captures are documented in [pillar screenshot provenance](pillar-screenshot-provenance.md). All are UI examples, not merchant results.

The existing `/videos/banner.mp4` film and `/videos/banner-loop.mp4` preview binaries are unchanged, including their existing 70-second content. The preview attaches its source within 240 px of the viewport; the full film is requested after its dialog opens. Trigger, dialog and close labels are localized. The inherited full film has no verified caption track; this is documented without inventing a transcript.
