## Method and limits

- A style tag hid three overlays that are not part of the product: the Vercel
  toolbar, the Apollo browser extension icon and the assistant launcher. No
  pixels were edited.
- The win rates are simulated comparisons, as the dashboard labels them. They
  are not shopper visits or sales.
- The Results page was not captured: the demo store has no recorded AI
  traffic, so it shows only an empty state.
- The All stores view (`/dashboard`) was not captured, because it lists a
  client's store.

To replace a screenshot, capture the same page the same way, keep the file
name, and update its row here.
