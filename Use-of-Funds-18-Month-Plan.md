## Month by month

### Phase 1 — Build + Design Partners (M1–M3) · ~€25–30K/mo
- **M1** — Close round, set up ops/legal. Harden the simulation engine + auto-fix pipeline to production quality. Finalize and submit Shopify App Store listing.
- **M2** — Onboard first 4–5 design partners with real catalogs. Instrument win-rate measurement end-to-end. Start first engineer hire.
- **M3** — ✅ **10 paying design partners live** with documented win-rate lift. Engineer joins. Launch the "AI agent optimization" content engine.

### Phase 2 — Public Launch + Self-Serve Scale (M4–M6) · ~€40–45K/mo
- **M4** — Public Shopify App Store launch. Self-serve onboarding live. Growth hire joins. Begin paid + content acquisition experiments.
- **M5** — Optimize the funnel (install → activate → pay). Publish first case studies. Ramp marketing spend. ~60–80 paying merchants.
- **M6** — ✅ **150 paying merchants.** Validate pricing/tiers. Begin WooCommerce freemium plugin build + scope enterprise pilots via Plug and Play.

### Phase 3 — Scale + Enterprise + WooCommerce (M7–M12) · ~€50–55K/mo
- **M7** — Launch WooCommerce freemium plugin on WordPress.org (cheap top-of-funnel). +1 engineer, +1 CS/sales.
- **M8** — Scale paying merchants; deepen the data corpus. Sign **first enterprise pilot** (PnP).
- **M9** — Optimize WooCommerce free→paid conversion. Expand content/SEO moat.
- **M10** — Scope/sign **second enterprise pilot**. Drive expansion revenue (tier upgrades).
- **M11** — Push ARR; focus on retention/churn. Build seed-round metrics and narrative.
- **M12** — ✅ **€450K ARR + 2 enterprise pilots live → seed-ready.**

### Phase 4 — Seed-Ready + Raise (M13–M18) · ~€40K/mo (offset by revenue)
- **M13–14** — Strengthen metrics: retention cohorts, win-rate lift case studies, unit economics. Build seed data room + deck.
- **M15–16** — Run the seed raise (warm intros, Day One follow-on). Keep growth steady.
- **M17–18** — Close seed; hold a 3–6 month buffer so you're never raising from zero. Transition into the seed plan.

## Cash view (why €750K lasts 18 months)

Gross burn rises with hires and marketing, but so does revenue. By M12 you're at ~€450K ARR (~€37K MRR), so in the back half revenue covers a large share of burn and **net** burn stays well inside €750K.

| Phase | Months | ~Gross burn | Note |
|---|---|---|---|
| 1 | M1–3 | ~€80K | Founders only, low spend |
| 2 | M4–6 | ~€125K | First hires + launch marketing |
| 3 | M7–12 | ~€320K | Peak hiring + scale; revenue starts offsetting |
| 4 | M13–18 | ~€240K | Revenue covers a big share; raise buffer |

The €750K funds the gross plan; growing MRR is what turns 18 months of spend into a comfortable runway with a buffer at the end.
