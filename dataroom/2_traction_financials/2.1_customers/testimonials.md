## Testimonial production process

For each new paying customer who hits the 30-day activation milestone:

1. CS sends a brief interview request (~15 minutes, can be async via written questions)
2. Three standard questions:
   - *What were you doing about AI shopping before écentic?*
   - *What changed since you started using écentic?*
   - *Is there one moment or metric that captures the impact?*
3. We draft a quote from the response, send back for approval
4. On approval, we add to this file and to the marketing rotation

Target: 1 new testimonial captured per month from M6 onwards (post-App Store launch).

## Permissions and audit trail

All testimonials used in public marketing must have written customer approval on file (email confirmation is sufficient). Verbal approvals are noted in this file with a date and a flag to follow up for written confirmation.

A permissions log is maintained alongside this document and updated whenever a testimonial is added, removed, or re-approved.
