# CJK fonts for social images

Noto Sans JP and Noto Sans SC are provided under their accompanying SIL Open Font License files. These fonts are server-side Satori assets; the browser uses native CJK font fallbacks.

Sources from the Google Fonts repository, downloaded 12 November 2026:

- https://github.com/google/fonts/tree/main/ofl/notosansjp
- https://github.com/google/fonts/tree/main/ofl/notosanssc

The variable TTF sources were instantiated at weight 600 using FontTools (`instantiateVariableFont(font, {"wght": 600})`). Full glyph coverage is retained for future translated blog titles. Keep these assets available in the deployment file trace.
